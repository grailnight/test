# Minigram

Лёгкий клиент Instagram для телефона: обычный мобильный сайт instagram.com,
из которого вырезано лишнее.

- **Нет Reels** — вкладка скрыта, адрес `/reels/` возвращает на главную, поток Reels не подгружается.
- **Нет рекомендаций** — из ленты убраны реклама, «Рекомендации для вас» и посты аккаунтов,
  на которые вы не подписаны; на странице поиска остаётся только сам поиск.
- **Нет бесконечной ленты** — показывается 10 постов из подписок, дальше плашка
  «Лента закончилась» с кнопкой «Ещё 10». Подгрузка в фоне тоже останавливается.

Сторис, директ, профили, поиск и публикация работают как на сайте. Вход — обычный, на самом
instagram.com; пароль приложение не видит и нигде не хранит.

Настройки (сколько постов за раз, скрывать ли видео в ленте) — кнопка ⚙ на плашке в конце ленты.

## Android

Приложение — в папке `android/`. Готовый APK собирает GitHub Actions при каждом изменении:
вкладка **Actions** → последний запуск **Build APK** → раздел **Artifacts** → `Minigram-apk`
(скачается zip, внутри `app-release.apk`); тот же файл сборка кладёт в `dist/Minigram.apk`. При установке Android попросит разрешить установку
из неизвестных источников.

Собрать самому: `cd android && ./gradlew assembleRelease` (нужны JDK 17 и Android SDK).

## iPhone и любой браузер

Файл `filter/minigram.user.js` — обычный юзерскрипт. На iPhone его можно подключить к Safari
через бесплатное расширение Userscripts, на Android — через Tampermonkey в Firefox.

## Если что-то перестало скрываться

Instagram часто меняет вёрстку. Вся логика — в `filter/minigram.user.js`:

- `JUNK_LABELS` — подписи, по которым пост считается рекламой или рекомендацией
  (сейчас русский и английский интерфейс);
- `ALWAYS_BLOCK`, `FEED_PAGING` — запросы подгрузки, которые блокируются.

Проверка фильтра на модели ленты: `node test/filter.test.js` (нужен Playwright).

Проект неофициальный и не связан с Instagram или Meta.
